## Documentación de proyecto (Estándar Nexoru)

Al cerrar cada fase, actualiza `PROJECT.md` (roadmap, specs vinculadas, decisiones clave,
pendientes, evidencia de validación y siguiente hito) y `docs/mapa-funcional.md` (agentes,
reglas y diseño por agente) para que reflejen lo construido. Si algo no coincide con
`specs/`, `specs/` es la fuente de verdad. Excepción: si el código y la documentación
técnica (`AGENTS.md`, README técnico, comentarios de esquema) coinciden entre sí y la spec
quedó desactualizada, se corrige la spec. Reporta siempre qué cambiaste, dónde y por cuál
de las dos vías.
